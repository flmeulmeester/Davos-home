# Davos@home
This page contains the scripts and R markdown files for the statistical analyses of the Davos@home RCT in severe asthma

## Step-by-step R Markdown files

Work in progress: this will be updated shortly.

1. DavosHome Markdown_pt1_Data_cleaning_MeulmeesterFL: Data cleaning and screening
2. DavosHome Markdown_pt2_Missingness_MeulmeesterFL: Plotting missingness patterns in patient-reported exacerbation data
3. DavosHome Markdown_pt3_Baseline_Table_MeulmeesterFL: Table 1 baseline characteristics of the study population
4. DavosHome Markdown_pt4_Multiple_imputation_MeulmeesterFL: Multiple imputation of the primary outcome, time-to-first-severe-exacerbation with risk score imputation, and secondary outcomes with MICE
5. DavosHome Markdown_pt5_Primary_outcome_Time_to_event_MeulmeesterFL: Time-to-first-severe-exacerbation (primary outcome) in complete data and imputed data; including worst-case scenario analysis where 2 consecutive missing weeks count as an exacerbation (sensitivity analysis)
6. DavosHome Markdown_pt6_Exacerbations_Hospi_ER_Sankey_MeulmeesterFL: Number of exacerbations, hospitalisations and ER visits (secondary outcomes), plotted in a Sankey diagram
7. DavosHome Markdown_pt7_EM_means_PROMs_MeulmeesterFL: Estimated marginal means of patient-reported outcome measures ACQ, AQLQ, CIS-F, HADS, WPAI and ICS FP equivalent, including plots
